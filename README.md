# Computer Vision Projects

Separate projects with their own code, results and setup instructions.

| Project | Code and guide | Stack | Status |
|---|---|---|---|
| Menu Detector | [Open project](menu-detector/) | PyTorch, MobileNetV2, CLIP | 93.7% validation accuracy; 94.8% balanced accuracy |
| Webcam Face Detection | [Open project](face-detection/) | Python, OpenCV, Haar Cascades | Laptop webcam demo; also tested on a phone-displayed photo |
| Unity AR Face Tracking | [Open project](unity-ar-face-tracking/) | C#, AR Foundation, ARCore | Original Android coursework tested; reconstructed scripts await device retest |
| Learning notebooks | [Open notebooks](learning-notebooks/) | OpenCV, PyTorch, Matplotlib | Foundational exercises |

## Quick start

- **Menu Detector:** [Open in Colab](https://colab.research.google.com/github/khodiboev/computer_vision/blob/main/menu-detector/menu_detector_model.ipynb), then follow its [README](menu-detector/README.md).
- **Webcam detector:** follow the [local Python setup](face-detection/README.md). A GitHub link opens source code, not your camera.
- **Unity AR:** follow the [Android coursework setup](unity-ar-face-tracking/README.md); this is not a ready-to-install APK.

Unity AR face tracking and OpenCV face detection are separate implementations. Neither module identifies who a person is.
